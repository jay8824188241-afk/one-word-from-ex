One word an ex would use to describe the entrant: **almost**. Not an insult — the quiet verdict underneath every almost-relationship. It lands instantly, needs no explanation, and cannot be swapped for a near synonym without losing its edge. `main.py` writes exactly that word to `/output/entry.txt`, and nothing else.

## Run it

```sh
python3 main.py
```
